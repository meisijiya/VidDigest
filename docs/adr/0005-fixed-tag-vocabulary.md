# 标签取自人工维护的固定词表，不允许模型自创

社区需要「按标签查找」。若让模型自由生成标签，会出现「AI 编程」「编程教学」「代码讲解」这类近义标签并存，
标签体系逐渐碎片化，分类页内容稀疏，检索体验崩坏。
因此维护一份固定词表，模型只能从中选择，不能创造新词。

## Consequences

词表由人工维护，新增标签需改代码。这带来一个明确的好处：标签可枚举，
每个分类页永远有内容，且分类语义稳定。

## Considered Options

- 允许模型自创标签：灵活、覆盖广，但半年后必然碎片化，且无法保证「按标签找视频」这个功能真正可用。
