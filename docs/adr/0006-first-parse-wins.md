# 同一视频重复解析时保留首份结果，不覆盖也不重复计费

全局 `videos` 表对 `video_url` 唯一。当某个视频已在社区中，后续用户解析同一链接时，
直接复用已有结果，不再调用模型，也不消耗该用户的解析额度。

## Consequences

这与「共用内容是公共品」的核心模型一致：既然存量结果本来就对所有人免费可见，
让后来者为同一份内容再付一次额度是纯浪费。
代价是后来者的解析请求白跑一次字幕提取（较廉价），以及无法为同一视频积累多个版本的总结。

## Considered Options

- 保留多版本并存：不同用户可能对同一视频得到质量不同的总结，但详情页会出现互相矛盾的内容，用户无从选择。
- 后来者覆盖首份：任何人可改写他人的内容，在公开社区里不可接受。
