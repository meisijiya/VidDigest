【第一部分：总结正文】
一、格式（照做即可）
1. 必须输出标准 Markdown，并使用多级标题构建清晰的层级结构：
   - `# 视频主题`：一级标题，全文有且仅有一个；
   - `## 章节`：二级标题作为主要章节（如 视频概述 / 内容大纲 / 核心知识要点 / 总结）；
   - `### 小节`：三级标题用于章节内部的细分要点。
2. 严禁用 `**加粗**` 代替标题，所有章节标题都必须以 # 号开头独占一行。
3. 章节内部的要点使用无序列表（`- `）呈现，子要点通过缩进（`  - `）形成层级，禁止整段堆砌文字。
4. 只输出 Markdown 正文，不要输出代码块围栏，也不要任何解释性文字。

二、内容（比上面四条格式更重要，务必遵守）
5. 这是**摘要**，不是目录。每一条要点都必须写出实质内容——具体的事实、数据、
   结论、观点，或它和其它要点的因果关系。**严禁**只把小标题换个说法：
   - 反例：`成本分析：不同模型的 API 费用对比`（只说了这节要讲什么，没有内容）
   - 反例：`做法介绍：介绍这道菜的基本做法`（同上）
   - 正例：`做法介绍：先用盐水浸泡 20 分钟去腥，两面煎至金黄后转小火慢炖 40 分钟`
   - 正例：`模型表现：横测里它在代码任务通过率最高，但长上下文出现了明显退化`
6. **覆盖优先**：字幕里出现过的每一个主要话题都要讲到，不要因为「看起来不重要」
   就略过；拿不准要不要展开的次要话题，也用一句话把它带过。
7. **篇幅**：正文不少于 1500 字（不含标题行）。宁可把一个话题的背景和因果讲透，
   也不要列一堆小标题就收尾；同时不要用重复的话凑字数。
8. 字幕里没有的信息不要编造。听不清、字幕本身就没展开的部分，直接略过。

【第二部分：思维导图】
（下面的长度与节点数限制**只适用于思维导图**，不要套用到第一部分的总结正文。
导图刻意精简、总结正文刻意详实，这是两件不同的事。）
只输出 Markdown 标题层级结构，禁止代码块围栏、禁止任何说明、问候或总结性文字：
- `# 视频主题`：一级标题，有且仅有一个，作为导图中心主题；
- `## 主要章节`：二级标题，作为一级分支（一般 3-6 个）；
- `### 次级要点`：三级标题，作为二级分支；
- `- 细节要点`：无序列表，作为叶子节点（可选）。
每个节点文字尽量不超过 15 个字，全图节点总数控制在 30 个以内。

# 视频主题
## 视频概述
- 本期实测三款家用扫地机器人，场地是同一套 120㎡ 三居室，铺同一种木地板
- 主要对比吸力、越障高度和尘盒清理方式，测试周期两周，每天同一时间各跑一遍
- 三款定价依次为 2199、1299、899 元，差价主要来自导航方案和尘盒结构
## 吸力表现
- 甲机标称 5000Pa，在地毯上的残留量最低，边缘清扫漏得也最少
- 乙机 3500Pa，硬地板够用，但一旦铺上地毯，床底和墙角会明显残留
- 丙机只有 2500Pa，日常够用，代价是宠物毛发要多跑一遍才能收干净
## 越障与脱困
- 门槛测试设了 1.5cm 和 2cm 两档：只有甲机能过 2cm，乙机和丙机都卡在 1.5cm
- 卡住之后三款行为差别很大：甲机会减速换个角度再试，其余两款直接停在原地
- 地毯边缘的脱困测试里乙机成功率最低，重复三次里有一次彻底没出来
## 尘盒与维护
- 甲机尘盒可水洗，清理时不必反复倒灰，这是它日常体验加分最多的一点
- 乙机的尘盒滤网网孔偏密，两周后堵得比预想快，每次清理都得拿刷子挑
- 丙机尘盒是密封设计，不挑灰但不能水洗，长期发霉的风险要自己承担
## 结论
- 追求清洁效果优先选甲机，代价是价格约为另外两台的两倍
- 预算有限又不想牺牲越障能力的话，丙机比乙机更均衡
- 三款共同的短板是都不能自清洁拖布，都得手动拆洗
