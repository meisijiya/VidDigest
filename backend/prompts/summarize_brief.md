请对以下视频字幕内容做一次精简分析，一次给出三样东西：总结、思维导图、标签。使用$lang_hint输出。

【第一部分：总结正文】
一、格式（照做即可）
1. 必须输出标准 Markdown，并使用多级标题构建清晰的层级结构：
   - `# 视频主题`：一级标题，全文有且仅有一个；
   - `## 关键要点`：二级标题作为分组（如 结论 / 数据 / 风险 / 建议），一般 3-5 个；
   - `### 小节`：三级标题用于分组内部的细分要点。
2. 严禁用 `**加粗**` 代替标题，所有章节标题都必须以 # 号开头独占一行。
3. 章节内部的要点使用无序列表（`- `）呈现，子要点通过缩进（`  - `）形成层级，禁止整段堆砌文字。
4. 只输出 Markdown 正文，不要输出代码块围栏，也不要任何解释性文字。

二、内容
5. 每一条要点都要**自成一句完整的话**：把结论、数据或判断本身写出来，
   不要只把小标题换个说法，也不要写「详见上文」这种要读者自己拼的句子。
   - 反例：`价格优势明显`（只说了结论，没有依据）
   - 正例：`官方定价 1999，同配置竞品普遍 2499 起，差价主要来自渠道`
6. **覆盖优先**：字幕里出现过的每一个主要结论都要讲到，拿不准要不要展开的
   次要话题，用一句话带过即可。
7. **篇幅**：正文 300-600 字（不含标题行）。本模板只求**准**，不求**全**：
   每条要点写清结论本身，不展开背景与铺垫，也不要为了写满而注水。
8. 字幕里没有的信息不要编造。听不清、字幕本身就没展开的部分，直接略过。

【第二部分：思维导图】
（下面的长度与节点数限制**只适用于思维导图**，不要套用到第一部分的总结正文。
导图刻意精简、总结正文刻意精简，这是两件不同的事。）
只输出 Markdown 标题层级结构，禁止代码块围栏、禁止任何说明、问候或总结性文字：
- `# 视频主题`：一级标题，有且仅有一个，作为导图中心主题；
- `## 主要章节`：二级标题，作为一级分支（一般 3-6 个）；
- `### 次级要点`：三级标题，作为二级分支；
- `- 细节要点`：无序列表，作为叶子节点（可选）。
每个节点文字尽量不超过 15 个字，全图节点总数控制在 30 个以内。
导图的结构上限（超出的部分会被截断，所以要自己控制）：
- 层级最多 3 级：`#` → `##` → `###`，不要出现 `####`；
- 同一个父节点下最多 7 个子节点；
- 至少 2 个二级分支，每个分支下再挂 1-2 个三级要点——只有一层等于没给。

【第三部分：标签】
（同样只约束标签本身，不影响前两部分。）

判断依据是这个视频**在讲什么题材**，不是「它对某个行业有没有用」：
一段讲劳动仲裁的普法视频属于职场题材，哪怕观众大多是做技术的。

从下列固定词表中选出最多 3 个最贴切的标签，必须用词表里的中文原词，
不要自创近义词（例如不要写「AI 编程」「编程教学」）：
$vocabulary

「其他」只在题材真的不属于上面任何一类时才用。拿不准就选最接近的那一类，
不要直接落到「其他」——它是最后的兜底，不是「不确定」的同义词。

判断示例，每行左边是题材、右边是应选的标签，标签都取自上面这张表：
  用 Python 写爬虫踩坑              → 编程
  横向对比几个大模型的编程能力        → 人工智能、编程
  实习生被违法解除该怎么办            → 职场维权
  某地土地财政与房价走势              → 财经投资、时事评论
  盘点国庆游戏打折到底值不值          → 游戏、电商优惠
  三款扫地机器人横测                 → 数码测评
  一个人把游戏发行跑通                → 游戏、创业
  讲金庸武侠小说的写作背景            → 读书、影视

【输出格式 —— 必须严格遵守】
第一部分正文之后，另起一行输出哨兵行（一个字都不能改，也不要加代码块围栏）：
$sentinel
紧接着输出一行 JSON，形如：
{"mindmap": "# 视频主题\n## 主要结论\n### 结论要点\n## 关键数据\n### 对比数据", "tags": ["编程", "人工智能"]}

完整示例（每条要点都是一句话的结论，正文整体偏短）：
# 露营装备怎么买不踩坑
## 一句话结论
- 先买帐篷与睡袋，再买天幕，照明和炊具最后补
## 预算怎么分
- 六成预算给帐篷和睡袋，这两样直接决定能不能睡好
- 炊具与照明买一套入门款即可，很多营地有公共设备可以借
## 最容易买错的三件
- 帐篷只看防水指数不看重量，扛不动等于没买
- 睡袋的舒适温度要比当地夜间气温低 5 度，否则夜里会冷醒
## 出发前
- 前一天完整试装一次，真搭过才知道杆子会不会少一根
$sentinel
